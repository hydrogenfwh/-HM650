# 华为-HM650
华为擎云 HM650，7199 元到底值不值？我把原来的芯片跑分、整机价格和公开采购记录重新查了一遍。我的判断是：普通消费者和一般企业不建议买。有明确国产化要求的单位，可以把它放进候选名单，但现有公开证据还不足以支撑 7199 元

本资料比较华为擎云 HM650（麒麟 X90、16 GB 内存、512 GB SSD）与 Apple、Intel、AMD 设备及国内商用台式机。7199 元是媒体报道的配置参考价。公开采购案例的单价对应各自的配置、数量和服务，实际采购需要统一条件询价。
